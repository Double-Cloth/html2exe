# 项目检查记录

检查日期：2026-10-19。保留 Electron/CommonJS 技术栈和现有界面体系。

## 已修复

- 构建锁覆盖准备阶段；取消安装与构建进程树，异常、取消和启动失败统一收尾，避免双重清理与临时工程泄漏。
- 缓存清理限定在应用目录，不再按路径匹配并结束其它进程；构建与清理互斥。
- 前后端共用配置校验，修正四段 Chromium 版本被拒绝的问题，拒绝字符串伪布尔值、非法架构和冲突安装器选项。
- 配置增量更新串行执行并原子替换，防止并发覆盖和半写入；支持 BOM 导入和自定义下拉框选项。
- 输出目录拒绝源码及祖先目录；自打包清理同样验证目录链接指向，避免越界删除。
- 修复纯 HTML 复制受上级目录名称影响的问题，保留排除规则，附加资源按原始目录定位；只处理选中平台的图标。
- 保留项目未被界面覆盖的构建钩子和设置，遵守用户的 `asar` 选项，补充生成应用的 macOS 激活处理。
- 限制特权 IPC 的调用页面与框架，加入 CSP、导航与新窗口限制，以及应用单实例控制。
- 内置 npm，所有工具直接通过运行时启动，修复 Windows `npm.cmd` 的调用问题；工具链用独立清单和锁文件准备、校验和复用。
- portable 模板逻辑集中到一个模块，仅影响构建子进程读取，取消和崩溃均不会改写共享依赖。
- 移除工具链重复复制；自打包发布同时保留 ZIP 和更新辅助文件，发布失败保留可恢复的临时产物。
- 修复配置页错误反馈、快速连击、构建期间导航、日志无限增长、邮箱/网址输入框样式及部分文字对比度。

## 验证

- `npm test`：59 项通过，包含真实子进程取消、并发保存、目录链接、失败清理、模板不落盘和产物发布测试。
- 真实 Electron 界面：1280×840 和 1080×680，验证标签切换、保存/导入、自定义目标、四段 Chromium 校验、失败提示与按钮恢复；页面控制台无错误。
- Windows x64 portable 自打包通过；工具链必需文件校验通过。
- 在系统 Node/npm 不可见的环境中，使用 Electron 后备运行时打包纯 HTML 项目；生成的 EXE 可启动并响应页面点击，排除文件未进入产物，附加资源存在。
- Linux/macOS 实机、签名证书、公证和所有架构组合未做端到端验证。
